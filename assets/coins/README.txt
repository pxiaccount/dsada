Put custom coin photos in this folder.

Suggested format: square PNG or JPG, 1024 x 1024 px, coin centred and
filling the frame. Reference them from `js/coins.js`:

  frontImage: 'assets/coins/my-coin-front.png',
  backImage:  'assets/coins/my-coin-back.png',
  imageRelief: 0.8

See README.md for the full guide.
